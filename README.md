# Daily-driving — Drive Safe Tracker

An Android app that helps drivers monitor their weekly driving habits to promote road safety.

## About
Drive Safe Tracker allows users to log their daily driving habits over a week,
including hours driven, rest stops taken, and hours slept. The app helps users
identify dangerous driving patterns and make safer decisions on the road.

## Features
- Log driving data for each day of the week
- View total hours driven for the week
- See which day had the most driving
- View average hours slept per night
- Receive personalised safety feedback

## Screens
1. **Welcome Screen** — app introduction with Start and Exit buttons
2. **Input Screen** — enter daily driving data day by day
3. **Details Screen** — view weekly summary and personalised feedback

## Built With
- Kotlin
- Android SDK
- ConstraintLayout
- Multi-activity navigation with Intents

## How to Run
1. Clone the repository
2. Open in Android Studio
3. Build and run on an emulator or physical device (min SDK 26)
