# Daily-driving — Drive Safe Tracker

## About
The Drive Safe Tracker app allows users to log their daily driving habits
over a week including hours driven, rest stops taken, and hours slept.
The app helps users identify dangerous driving patterns and make safer decisions.

## Features
- Log driving data for 7 days
- View total hours driven for the week
- See which day had the most driving
- View average hours slept per night
- Receive personalised safety feedback

## Screens
1. Welcome Screen — app introduction with Start and Exit buttons
2. Main Screen — input daily driving data day by day
3. Details Screen — view weekly summary and personalised feedback
